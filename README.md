# Audrey Deng

Portfolio website for writer and illustrator Audrey Deng.

## Local development

```bash
npm install
npm start
```

## Site sections

- About
- Writing
- Illustration
- CV link in the header and about page

## Notes

This repository contains the public portfolio for Audrey Deng. Public contact links are intentionally kept visible, but the starter/template files from the previous theme were removed from the project.
